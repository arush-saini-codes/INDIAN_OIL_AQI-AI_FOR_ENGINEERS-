# Raw Data Instructions (`data/raw/`)

Raw CSV files are excluded from Git tracking (`.gitignore` ignores `data/raw/*.csv` and `data/raw/*.zip`) due to repository size limits (the hourly files exceed 285 MB combined).

---

## Dataset Source
- **Dataset Title**: *Air Quality Data in India (2015–2020)*
- **Author**: Rohan Rao (Vopani)
- **Source**: Kaggle ([`rohanrao/air-quality-data-in-india`](https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india))
- **Origin**: Central Pollution Control Board (CPCB) India, official ambient monitoring archive.

---

## Download & Placement

### Option A: Manual Download
1. Visit [https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india](https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india).
2. Download and unzip the archive.
3. Place the extracted CSV files directly inside this directory (`data/raw/`).

### Option B: Kaggle CLI
```bash
pip install kaggle
kaggle datasets download -d rohanrao/air-quality-data-in-india -p data/raw --unzip
```

## Required Files & Usage in This Project

| Filename | Size | Used in Pipeline? | Purpose |
| :--- | :---: | :---: | :--- |
| `city_day.csv` | ~2.5 MB | **Yes (Primary)** | Daily Chennai city-level AQI and pollutant time series (2015–2020) |
| `station_day.csv` | ~8.6 MB | **Yes (Audit)** | Daily station-level readings (used to audit Chennai stations TN001–TN004 & verify the Sep 2016 CO sensor fault) |
| `stations.csv` | ~14 KB | **Yes (Metadata)** | Station IDs, names, cities, and statuses |
| `city_hour.csv` | ~65.6 MB | No | Hourly city series (bypassed per daily granularity decision) |
| `station_hour.csv` | ~219.7 MB | No | Hourly station series (bypassed per daily granularity decision) |

> **Note:** Processed splits (`train.csv`, `val.csv`, `test.csv`, `stress.csv`) are generated by executing [`notebooks/03_preprocessing.ipynb`](../../notebooks/03_preprocessing.ipynb) and are saved in `data/processed/`.
